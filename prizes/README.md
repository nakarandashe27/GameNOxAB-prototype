Призы 1–3 — работа студии, поэтому у каждого записан объём: один объект, до 5 кадров, до 3 рендеров. Без этого суперприз превращается в бесконечный проект.

## Вместе с призами школы: круг из 12 секторов

| Секторов | Приз | Чей |
|---|---|---|
| 1 | 3D-модель проекта | студия |
| 1 | 5 визуализаций для проекта | студия |
| 1 | Место на экскурсии в архбюро | школа |
| 2 | Улучшение визуализаций | студия |
| 3 | Скидка 10% на любой курс, не суммируется с комбо | школа |
| 4 | Материалы: чек-лист визуализации, промпты на улучшение, промпты на пролёты, чек-лист по ИИ | студия и школа |

## Как выпадает

Круг — витрина, исход выбирает сервер по весам и остаткам (Р16).

- **3D-модель** — только на 7-м листе, то есть среди тех, кто собрал проект целиком, и пока есть остаток. Это повод дойти до конца недели.
- **5 визуализаций** — около 1% на спин, **улучшение** — около 3%, пока есть остаток.
- **Экскурсия** — пока есть места в группе.
- **Скидка 10%** — с 3-го листа, одна на аккаунт.
- **Остальное — материалы.** Выпадают без повторов. Когда собраны все четыре, выпадают отдельные промпты из общего пула (Р6).

Для Р6 студия готовит 20 промптов вместо 15: два набора по 10.

## Как это устроено в игре

- Круг из 12 секторов, исход выбирает `pickOutcome` по весам и остаткам `S.stock`; один приз студии на аккаунт.
- Материалы выдаёт `nextMaterial` по порядку без повторов, после всех четырёх — отдельные промпты из 20 студийных.
- Промпты листаются и копируются прямо в карточке приза и в «Моих призах» — экран не прокручивается.
- Тексты промптов берутся при сборке игры из [src/prompts.json](src/prompts.json): правка в одном месте меняет и PDF, и игру.
- До запуска нужно: подключить реальную выдачу (коды скидки, уведомления студии и школы, отправку PDF ботом), получить чек-лист школы по ИИ и опубликовать правила акции (Р17).

## Сборка PDF

Три разные вёрстки по брендбуку «Нейро Отличник» V.1: чек-лист — чертёжный лист A4 (`checklist.html`, `sheet.css`), улучшение — тёмная презентация A4 альбомом, пролёты — сторис 9:16 (`layouts.py`). Печать — headless Chrome, галочки — поля PDF.

```bash
python3 prizes/src/build.py
```

Нужны Google Chrome, `pip install pymupdf` и проект neuro-maket: шрифты Kica и Inter Tight берутся оттуда и в репозиторий не входят. Другой путь к проекту — флаг `--brand`.

Тексты промптов правятся в [src/prompts.json](src/prompts.json), чек-лист — в [src/checklist.html](src/checklist.html). Сборка заново пишет PDF и `.md` с промптами.
