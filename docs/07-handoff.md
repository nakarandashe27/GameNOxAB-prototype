# Передача работы другому агенту

Файл для ИИ-агента или разработчика, который продолжит работу. Прочитать первым, до правок кода.

## 1. Что это

«Собери проект» — мини-игра для коллаборации школы **АРТ.БРОДСКИЙ** и студии нейровизуализации **Нейроотличник**. Матч-3 в Telegram Mini App: неделя = один объект, семь дней = семь стадий проекта (генплан → планы → разрезы → фасады → материалы → свет → визуализация). Каждая сдача открывает слой визуализации и даёт спин рулетки с призом: промпт, скидка на интенсив или приз студии.

Игра обслуживает эфир и прогрев к октябрьскому интенсиву. Лид — подписчик канала, не обладатель промокода.

Сейчас готов **кликабельный прототип v0.3**, не боевая версия. Серверной части, бота и реальных призов нет.

## 3. Структура кода

```
prototype/core.js        ядро матч-3 без DOM: поле 7×7, свапы, каскады, цели стадий, объекты недель
prototype/index.html     весь интерфейс: экраны, анимации, рулетка, визуализация-заглушка, заметки справа
prototype/dist/          сборка, НЕ РЕДАКТИРОВАТЬ РУКАМИ
tools/build-prototype.js сборка dist из index.html + core.js
tools/balance-sim.js     симуляция баланса целей
.github/workflows/       деплой на GitHub Pages при пуше в main
```

Зависимостей нет: ни npm-пакетов, ни сборщика. Нужен только Node.js 18+ для двух скриптов.

## 4. Как работать

```bash
node tools/build-prototype.js        # пересобрать dist после любой правки
node tools/balance-sim.js 1200       # проверить баланс после правки целей или ходов
python -m http.server 8765           # открыть prototype/dist/soberi-proekt.html в браузере
```

Правила, которые нельзя нарушать:

1. **Правки только в `prototype/index.html` и `prototype/core.js`.** `dist/` — результат сборки, его перезапишет скрипт.
2. **После каждой правки — пересборка.** Иначе живая версия и файл для пересылки разойдутся.
3. **Баланс меняется только через `STAGES` и `MOVES_PER_STAGE` в `core.js`**, и каждое изменение проверяется симуляцией. Целевая проходимость — около 90 % у обычного игрока.
4. **Никаких внешних библиотек и запросов.** Прототип должен открываться двойным кликом по одному файлу, без интернета (кроме шрифтов Google).
5. **Ядро остаётся без DOM.** `core.js` подключается и в браузере, и в Node — на нём же будет серверная проверка сдачи.
6. **Поле детерминировано сидом.** Ломать детерминизм нельзя: на нём держатся общее поле дня и защита от накрутки.
7. **Тексты — на русском**, в стиле чертёжной документации: лист, штамп, стадия, сдача. Ведущий — «Отличник», говорит коротко и с иронией.
8. **Исходный PDF концепта не коммитить** (`.gitignore`), репозиторий публичный.
9. Деплой автоматический: пуш в `main` → GitHub Actions → ветка `gh-pages` → Pages. Отдельных действий не нужно.
