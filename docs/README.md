# Собери проект — рабочая папка

Мини-игра для коллаборации школы **АРТ.БРОДСКИЙ** и студии нейровизуализации **Нейроотличник**.
Матч-3 в Telegram Mini App: неделя = объект, 7 дней = 7 стадий проекта, в конце недели открывается рендер.

Статус на 15.09.2026: **концепт v1.0 + кликабельный прототип**. Эфир ориентировочно 23.09.2026 (среда) — это Д−8.

## Как смотреть прототип

1. Открыть https://nakarandashe27.github.io/GameNOxAB-prototype/ или файл `prototype/dist/soberi-proekt.html` двойным кликом.
2. Слева — телефон с игрой, справа — заметки к текущему экрану и «режим показа»: сдать стадию сразу, прогулять день, прыгнуть к любому дню, выбрать приз следующего спина.
3. Прогресс хранится в браузере; «Сбросить прототип» возвращает к дню 1.

Что в прототипе **настоящее**: поле 7×7, свапы, каскады, детерминированное поле дня, цели стадий, ходы, доработка, сдача с замечаниями, неделя и отсрочки, слои визуализации, рулетка, карточка дня.
Что **заглушка**: рисунок вместо рендера студии, 8 примеров промптов вместо 30, промокод, проверка подписки, отправка в чат.
