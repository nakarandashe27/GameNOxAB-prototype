# Собери проект — прототип

Мини-игра для коллаборации школы **АРТ.БРОДСКИЙ** и студии нейровизуализации **Нейроотличник**: матч-3 в Telegram Mini App, где неделя — это объект, а семь дней — семь стадий проекта, от генплана до визуализации.

**Смотреть прототип:** https://nakarandashe27.github.io/GameNOxAB-prototype/

Слева — телефон с игрой, справа — заметки к текущему экрану и «режим показа»: сдать стадию сразу, прогулять день, перейти к любому дню, выбрать приз следующего спина.

## Что внутри

| Путь | Что это |
|---|---|
| `prototype/core.js` | Ядро матч-3 без DOM: детерминированное поле, свапы, каскады, цели стадий. Одно ядро для фронта, серверной проверки и симуляции |
| `prototype/index.html` | Прототип: экраны, анимации, рулетка, визуализация-заглушка, заметки для согласования |
| `prototype/dist/soberi-proekt.html` | Сборка одним файлом — можно переслать и открыть двойным кликом |
| `tools/build-prototype.js` | Сборка: `node tools/build-prototype.js` |
| `tools/balance-sim.js` | Симуляция баланса целей: `node tools/balance-sim.js 1500` |
| `docs/` | Разбор концепта, геймдизайн, ТЗ, реестр решений, план до эфира |

## Деплой

Каждый пуш в `main`, который меняет `prototype/` или сборку, запускает GitHub Actions: прогон симуляции как проверка ядра → сборка → публикация `index.html` в ветку `gh-pages` → GitHub Pages.

Статус: прототип для согласования, не боевая версия. Заглушки: рисунок вместо рендера студии, примеры промптов, промокод и проверка подписки.
